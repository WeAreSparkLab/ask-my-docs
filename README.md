# Ask My Docs

A RAG chatbot that answers questions from your documents, with citations.

> 🚧 Work in progress. Live demo link, architecture diagram, setup steps and evaluation results will be added as the project is built.

## Planned stack

React + Vite + TypeScript · Tailwind · Vercel serverless functions · Supabase (Postgres + pgvector, Auth, RLS, Edge Functions) · Anthropic API · Upstash Redis
